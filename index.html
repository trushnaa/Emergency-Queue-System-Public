📚 How It Works — Min-Heap Priority Queue

🏗️ Data Structure

A Min-Heap is a complete binary tree where every parent node has a value ≤ its children. We use it to always extract the highest-priority (lowest triage number) patient in O(log n) time.

⚙️ Key Operations

OperationComplexityDescription
insert()O(log n)Add patient → bubble up
extractMin()O(log n)Remove top → heapify down
peek()O(1)View next patient
size()O(1)Current queue length

🔄 Heap Property Maintenance

Bubble Up: After insertion, compare with parent and swap if smaller — repeat until heap property is restored.

Heapify Down: After extraction, move last element to root, then swap with smallest child — repeat until valid.

🏥 Triage Levels (Priority)

P1 — Resuscitation P2 — Emergency P3 — Urgent P4 — Semi-Urgent P5 — Non-Urgent
